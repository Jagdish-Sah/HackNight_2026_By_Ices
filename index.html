SECTION 1.0

Executive System Overview & Objectives

Institutional purpose, target user personas, and high-level architectural goals of GovTrace Hub.

Core Platform Objectives

GovTrace Hub ("govtrace-hub") is an operational, production-grade civic oversight portal built to transform how public money is tracked and audited.

  • Municipal Budget Monitoring: Track allocation vs disbursed funds across municipal sectors with real-time execution rates.
  • Public Official Asset Tracking: Compare declared assets from 2022 baseline to 2026 current wealth with automated anomaly detection.
  • Manifesto Promises: Track political promises with live percentage progress meters and target deadlines.
  • Crowdsourced Grievances: Enable citizens to file tickets with upvoting and live status updates.

Key Architectural Highlights

  • Serverless PostgreSQL Integration: Queries Neon Cloud PostgreSQL over HTTP/WebSocket via @neondatabase/serverless.
  • Zero API Boilerplate: Full integration of Next.js 16 Server Actions ('use server') for zero-latency server mutations and path revalidation (revalidatePath).
  • Multi-Level Audit Engine: 3-level deep drill-down UI (Level 1 Sectors → Level 2 Institutions → Level 3 JSONB Itemized Task Ledgers).
  • Automated Anomaly Detection: Built-in warning engines for >15% itemized cost markup and missing unaccounted fund discrepancies.

SECTION 5.0

Data Access Layer & Next.js Server Actions

Zero-API boilerplate asynchronous queries and mutations via lib/db.ts and lib/actions.ts.

lib/db.ts Dual Query Runners

To ensure high performance and prevent connection leaks during Next.js hot module reloading (HMR), lib/db.ts exports two query engines:

  • Neon Serverless Runner (sql): Direct HTTP/WebSocket SQL execution per request instantiated via neon(process.env.DATABASE_URL!).
  • Prisma Singleton (db): Global singleton instance attached to globalThis.prisma to preserve connection pools.

SECTION 6.0

Database Seeding & Hydration Pipeline

Automated database initialization CLI script (scripts/seed.ts) utilizing SQL DDL and UPSERT queries.

Seeding Execution Workflow

  1. DDL Table Creation: Executes CREATE TABLE IF NOT EXISTS across all 7 database tables.
  2. Idempotent Upsert Logic: Employs PostgreSQL ON CONFLICT DO UPDATE to overwrite existing mock data seamlessly without duplication errors.
  3. JSONB Embedding: Hydrates sub_department_data with itemized task lists containing expected baseline prices and actual disbursements.

Hydrated Production Datasets

  • 6 Municipal Departments: Roads, Health, Education, Sanitation, IT, Water Resources.
  • 4 Public Official Profiles: Baseline 2022 vs 2026 assets (e.g. Rajesh Sharma, Sita Adhikari) with declared land, shares, and anomaly flags.
  • 6 Manifesto Promises: Progress tracking for Smart Traffic, Digital Wards, Solar Lighting.
  • 6 KYC Verification Records: Identity NID checks and tax clearance dates.
  • 5 Public Complaints: Hydrated up to 215 citizen upvotes.

Budget Expenditure & 3-Level Audit Portal

Granular departmental audit drawer engine capable of detecting >15% itemized markups and unaccounted funds.

Level 1: Sector Master

Overview of municipal sectors (Roads, Health, Education) showing allocated vs spent funds and status indicators.

Level 2: Sub-Entities

Drill-down drawer detailing sub-institutions, regional offices, and specific municipal divisions.

Level 3: Itemized Ledger

Granular JSONB task ledger comparing actual vendor payment against market expected baseline prices.

Automated Anomaly Detection Triggers

1. Overpriced Cost Markup (>15%)

Automatically flags any itemized task where paid cost exceeds expected price by more than 15% with a ShieldAlert tag.

2. Unaccounted Missing Funds

Calculates sum of itemized ledger tasks and compares against entity claimed expenditure. Flags discrepancies where spent > task sum.

SECTION 7.4

Public Official Asset Disclosures & Anomaly Tracker

Wealth accumulation audit tracking declared assets from baseline 2022 to 2026 with South Asian NPR formatting.

Asset Growth Tracking Mechanics

  • Baseline Wealth Comparison: Stores baseline 2022 assets alongside 2026 declared holdings to calculate net wealth increase percentage.
  • Automated Anomaly Flagging: Flags officials whose wealth growth exceeds 100% or lacks declared income source justification.
  • Itemized Holdings: Itemizes declared land plots, real estate, gold reserves, stock shares, and foreign currencies.

Nepalese Rupee (NPR) Currency Formatter

Custom South Asian numbering format (en-IN) implementation for accurate NPR display:

export function formatNPR(amount: number): string { return new Intl.NumberFormat('en-IN', { style: 'currency', currency: 'NPR', maximumFractionDigits: 0 }).format(amount); }
