## 🚀 Overview

The Good Governance platform addresses administrative bottlenecks by offering streamlined tracking, reporting tools, and direct access to essential metrics. It serves as a tool for bridging the communication gap between communities and governing bodies.

## ✨ Features

* **Real-time Tracking:** Monitor governance metrics and ongoing public initiatives.
* **Citizen Feedback Portal:** A structured system for reporting local issues and suggestions.
* **Responsive Interface:** Designed for optimal performance across all devices.

---

## 💻 Tech Stack

* **Framework:** Next.js 16.3 (App Router)
* **Library:** React 19.2
* **Language:** TypeScript 5
* **Database:** Neon Serverless PostgreSQL
* **ORM:** Prisma ORM 6.3
* **Styling:** Tailwind CSS v4
